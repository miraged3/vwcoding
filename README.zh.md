## 项目简介

本网站使用 Markdown 标记语言构建。

页面模板示例：

```
    ### 编码/适配名称

    !!! tip ""
        如果需要，可在此处填写用途或说明

    !!! warning ""
        如有需要，可在此处补充警告信息

    ``` yaml title="登录-密码: XXXXX（如适用）"
    模块 XX → 适配/编码：
    字节 XX – 位 X（位名称）：激活
    部分名称：
    - 适配项名称：激活
    → 应用
    ```

    ??? note "折叠列表的标题"
        在网站上默认折叠显示的信息可以放在这里
```
